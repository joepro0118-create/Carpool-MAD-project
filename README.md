# UM-Ride

**UM-Ride** is a native Android, faculty-based campus carpooling application built for **Universiti Malaya (UM)** students and staff as part of **WIA2007 Mobile Application Development (2026/2027 Semester 1)**.

Aligned with **UN SDG 13: Climate Action**, UM-Ride connects verified UM commuters along shared lecture dismissal schedules and residential corridors to reduce single-occupancy vehicle (SOV) traffic, lower parking congestion, and track measurable carbon savings.

---

## Problem Statement

Universiti Malaya commuters face daily mobility bottlenecks during peak class dismissal hours (4:00 PM – 7:00 PM) and sudden tropical rainstorms:

* **For Non-Drivers:** Campus shuttle buses experience unpredictable intervals and overcrowding, last-mile transit to nearby LRT stations (LRT Universiti, LRT Kerinchi) is inconvenient, and commercial e-hailing platforms impose high surge fares.
* **For Student Drivers:** Faculty parking lots (e.g., FSKTM, Engineering, Law, Science, Business) are chronically congested, while single-occupancy drivers bear fuel and toll costs alone despite having empty seats.

---

## UN SDG 13 Alignment (Climate Action)

* **Target 13.2 (Integrate Climate Change Measures):** Reduces single-occupancy vehicle (SOV) traffic entering and exiting UM gates, lowering campus carbon emissions and parking demand.
* **Target 13.3 (Improve Education & Awareness):** Quantifies and visualizes individual and inter-faculty carbon offsets (`Distance_km * 0.192 kg CO2`) to encourage sustainable commuting habits across UM.

### Git Workflow
1. Always branch from `dev` (`git checkout dev && git pull origin dev`).
2. Commit changes to your assigned branch (e.g., `feat/ride-feed`).
3. Open a Pull Request (PR) into `dev` for code review before merging to `main`.
4. Never commit API keys, `local.properties`, or `google-services.json`.

## Local Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/joepro0118-create/Carpool-MAD-project.git
   cd Carpool-MAD-project
   git checkout dev
   ```

2. **Add Firebase configuration**
   * Download `google-services.json` from the team's Firebase Console project.
   * Place it inside the `app/` directory:
     ```text
     app/google-services.json
     ```
   * Verify that `google-services.json` is ignored by Git (`git status` should not list it).

3. **Configure API keys in `local.properties`**
   * Open (or create) `local.properties` in the project root directory.
   * Add your local Android SDK path (auto-generated by Android Studio) along with your Google Maps and Gemini API keys:
     ```properties
     sdk.dir=C\:\\Users\\<YourUsername>\\AppData\\Local\\Android\\Sdk
     MAPS_API_KEY=your_google_maps_api_key_here
     GEMINI_API_KEY=your_gemini_api_key_here
     ```

4. **Build & Run**
   * Open the project in **Android Studio**.
   * Click **Sync Project with Gradle Files**.
   * Run on an Android Emulator or physical device running **Android 8.0 (API 26)** or higher.
